Frequently Asked Questions

  • Is it safe to authenticate with my TikTok account?
    Yes. Authentication is performed exclusively via TikTok's official Login Kit using OAuth 2.0. We never receive or store your credentials.
  • Why is data loading taking a few moments?
    Retrieving activity logs via the Data Portability API involves asynchronous external queries to assemble lobby rounds accurately.
